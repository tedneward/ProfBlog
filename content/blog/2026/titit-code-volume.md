Code "ownership" is a red herring, we already got past that decades ago when we moved to team-based development. Agent-generated code will carry no more or less risk or weight than human-generated code.

Assuming developers still have to manage that code, how much can they reasonably manage? At what point does a human drown?

Supply-and-demand curves; if code is in vast supply, then equilibrium price of code goes down. But does code actually have a price? Can we price out a line of code?
